passkey-tpm — compatibility matrix

Local WebAuthn matrix for the target-site failure modes in plans/towards-0.2.0.md (M2).

Serve this file over localhost, not an IP address: 
python3 -m http.server 8765 --directory .
google-chrome-stable http://localhost:8765/browser-test-compat.html
Chrome treats http://localhost as a secure context; 127.0.0.1 may not work. Keep this tab focused. A scenario is running while its button is disabled. The page never transmits anything; everything stays in the browser.
